# AADT Mapping & Traffic Data Explorer
# The AADT Mapping & Traffic Data Explorer is a Python application that consolidates Annual Average Daily Traffic (AADT) data from multiple state Departments of Transportation into a single interactive mapping interface.
# Traffic count datasets vary significantly between states, with different file formats, coordinate systems, naming conventions, and attribute structures. This project standardizes those datasets into a common format, allowing analysts to quickly search, visualize, and inspect traffic count locations across the United States.
# The application was built to streamline transportation data analysis for site selection, market analysis, and commercial real estate workflows.
